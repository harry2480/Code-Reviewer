# AI-Review-Agent Repository レイヤー設計規約

Prisma ORM を使用したデータベースへのアクセスは、`src/backend/infrastructure/repositories/` に集約します。
UseCase、ローダー、アクションからは必ず Repository interface を通じてデータにアクセスします。

---

## 基本パターン

### Domain 層：Repository Interface 定義

```typescript
// src/backend/domain/repositories/review-history.repository.ts
export interface ReviewHistoryRepository {
  save(history: ReviewHistory): Promise<Result<void, RepositoryError>>
  findByPrId(prId: string): Promise<Result<ReviewHistory | null, RepositoryError>>
  findAll(limit?: number): Promise<Result<ReviewHistory[], RepositoryError>>
}
```

### Infrastructure 層：Repository 実装

```typescript
// src/backend/infrastructure/repositories/review-history.repository.ts
import 'server-only'
import { PrismaClient } from '@prisma/client'
import { ReviewHistoryRepository } from '@/backend/domain/repositories'

export class ReviewHistoryRepositoryImpl implements ReviewHistoryRepository {
  constructor(private readonly prisma: PrismaClient) {}

  async save(history: ReviewHistory): Promise<Result<void, RepositoryError>> {
    try {
      await this.prisma.reviewHistory.create({
        data: {
          prId: history.prId,
          reviews: JSON.stringify(history.reviews),
          timestamp: history.timestamp,
        },
      })
      return Result.ok(undefined)
    } catch (error) {
      return Result.err(new RepositoryError(`Failed to save: ${error.message}`))
    }
  }

  async findByPrId(prId: string): Promise<Result<ReviewHistory | null, RepositoryError>> {
    try {
      const record = await this.prisma.reviewHistory.findUnique({
        where: { prId },
      })
      if (!record) return Result.ok(null)
      return Result.ok(this.toDomain(record))
    } catch (error) {
      return Result.err(new RepositoryError(`Failed to find: ${error.message}`))
    }
  }

  private toDomain(record: any): ReviewHistory {
    // DB record to Domain Model への変換
    return ReviewHistory.create({
      prId: record.prId,
      reviews: JSON.parse(record.reviews),
      timestamp: record.timestamp,
    }).value!
  }
}
```

### Application 層：UseCase で Repository を注入

```typescript
// src/backend/application/usecases/execute-pr-review.usecase.ts
export class ExecutePrReviewUseCase {
  constructor(
    private readonly reviewHistoryRepo: ReviewHistoryRepository,
    private readonly githubGateway: GitHubApiGateway,
    private readonly aiGateway: AiEngineGateway,
  ) {}

  async execute(prPayload: PullRequest): Promise<Result<ReviewComment[], ReviewError>> {
    // ロジック実装
    const reviews = await this.performReview(prPayload)
    
    // Repository で永続化
    const saveResult = await this.reviewHistoryRepo.save({
      prId: prPayload.id,
      reviews,
      timestamp: new Date(),
    })
    
    if (saveResult.isError) {
      return Result.err(new ReviewError('Failed to save history'))
    }
    
    return Result.ok(reviews)
  }
}
```

## 実装ルール

### 1. `import 'server-only'` は必須

Repository は Server 専用。クライアントからのアクセスを防ぐ。

```typescript
import 'server-only'

// クライアントが import しようとするとコンパイルエラー
```

### 2. Repository の責務

**DB クエリ実行 + 第一レイヤーのエラーハンドリングのみ**

| すべき | すべきでない |
|---|---|
| SQL/Prisma クエリ実行 | ビジネスロジック |
| 基本的なエラーハンドリング（try-catch） | 複雑な集計・変換 |
| DB record → Domain Model への変換 | 認可チェック（UseCase で実施） |
| 単純な絞り込み（WHERE 句） | キャッシング制御 |

### 3. Error Handling: `Result<T, E>` を返す

```typescript
// ✅ OK
async save(entity: Entity): Promise<Result<void, RepositoryError>> {
  try {
    await this.prisma.table.create({ data: entity })
    return Result.ok(undefined)
  } catch (error) {
    return Result.err(new RepositoryError(error.message))
  }
}

// ❌ NG - Exception throw
async save(entity: Entity): Promise<void> {
  throw new Error('Failed to save')
}
```

### 4. Prisma クライアント管理

Prisma クライアントは Composition Root で単一インスタンス管理。

```typescript
// src/backend/infrastructure/db/prisma-client.ts
import { PrismaClient } from '@prisma/client'

let prisma: PrismaClient

if (process.env.NODE_ENV === 'production') {
  prisma = new PrismaClient()
} else {
  if (!global.prisma) {
    global.prisma = new PrismaClient()
  }
  prisma = global.prisma
}

export default prisma
```

### 5. トランザクション管理

複数テーブル操作は Prisma トランザクション使用。

```typescript
async updateWithHistory(entity: Entity, history: History): Promise<Result<void, RepositoryError>> {
  try {
    await this.prisma.$transaction(async (tx) => {
      await tx.entity.update({ ... })
      await tx.history.create({ ... })
    })
    return Result.ok(undefined)
  } catch (error) {
    return Result.err(new RepositoryError(error.message))
  }
}
```
