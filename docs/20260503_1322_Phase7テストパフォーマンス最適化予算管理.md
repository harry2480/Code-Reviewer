#### 7.3.2 日次上限ハードリミット

**実装内容:**

```typescript
// domain/services/budget-manager.service.ts

export class BudgetManager {
  async canSpend(tokenCount: number): Promise<Result<boolean, BudgetError>> {
    const today = this.getTodayKey()
    const spent = await this.ledger.getTodaySpent(today)
    const limit = await this.repository.getDailyLimit()
    
    const costUsd = this.estimateCost(tokenCount)
    const wouldExceed = spent + costUsd > limit.value
    
    if (wouldExceed) {
      return Result.error('DAILY_LIMIT_EXCEEDED')
    }
    
    return Result.ok(true)
  }
}
```

**UseCase:** `CheckBudgetAndExecuteReviewUseCase`（ExecutePrReviewUseCase をラップ）
- PR レビュー実行前に予算チェック
- 超過時は Checks API に「Budget Exceeded」と表示
- ログに記録

**成果物:**
- CheckBudgetAndExecuteReviewUseCase 実装
- 既存の Webhook handler に統合
- テストケース追加
