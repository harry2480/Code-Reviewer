# AI-Review-Agent スタイルガイド

Tailwind CSS + shadcn/ui に関するプロジェクト共通のスタイルルール。

Next.js 15 App Router、Server Components デフォルト、ダークモード対応を前提とします。

---

## shadcn/ui コンポーネント優先

### ルール

- **UI コンポーネントは shadcn/ui から選択する**。目的に合うコンポーネントがある場合、カスタム実装は禁止
- **カスタムクラスは `tailwind.config.ts` で定義し、プロジェクト全体で再利用可能にする**
- **直に `style={}` インラインスタイルを書かない**。必ず Tailwind クラスで表現

### 理由

- shadcn/ui は Radix UI 上に構築されており、アクセシビリティ（WCAG 2.1 AA）とダークモード対応が組み込まれている
- インラインスタイルは保守性・ダークモード対応の障害になる

### 具体例

```tsx
// NG - 独自実装 + インラインスタイル
<div style={{ backgroundColor: '#f3f4f6', padding: '16px' }}>
  <button style={{ color: 'white', background: '#3b82f6' }}>
    Submit
  </button>
</div>

// OK - shadcn/ui コンポーネント + Tailwind クラス
import { Button } from '@/components/ui/button'

<div className="bg-gray-100 p-4">
  <Button variant="primary">Submit</Button>
</div>
```

## カラーパレット・テーマ色

### ルール

- **テーマ色（Primary, Secondary, Danger, Success等）は `tailwind.config.ts` の `theme.colors` で定義**
- **ハードコード色（`#fff`, `#000` など）は禁止**
- **ダークモード対応**: `dark:` プレフィックスで暗色スキーム定義（shadcn/ui デフォルト）

### カラーマッピング

| 用途 | Tailwind クラス | 説明 |
|---|---|---|
| 背景 | `bg-background` | ページ背景（ダークモード対応） |
| 前景テキスト | `text-foreground` | 標準テキスト |
| Primary | `bg-primary text-primary-foreground` | アクション・重点ボタン |
| Secondary | `bg-secondary text-secondary-foreground` | 副次ボタン |
| Danger | `bg-destructive text-destructive-foreground` | 危険操作（削除等） |
| Success | `bg-green-600` | 成功状態 |
| Warning | `bg-yellow-600` | 警告状態 |
| Info | `bg-blue-600` | 情報表示 |
| Muted | `text-muted-foreground` | 補足テキスト・プレースホルダー |
| Border | `border-input` | フォーム枠線・区切り線 |

### 具体例

```tsx
// NG - ハードコード色
<div className="bg-[#ffffff] border-[#e5e7eb]">
  <button className="bg-[#3b82f6] text-[#ffffff]">Action</button>
</div>

// OK - テーマ色定義
<div className="bg-background border border-input">
  <Button variant="default">Action</Button>
</div>
```

## レスポンシブデザイン

### ブレークポイント

| 区分 | Tailwind | 用途 |
|---|---|---|
| Mobile | 無指定（`sm:` 未満） | ≤ 639px |
| Tablet | `md:` | 640px ～ 1023px |
| Desktop | `lg:` / `xl:` | ≥ 1024px |

### ルール

- **Mobile First**: 基本スタイルは `sm:` なし（モバイル優先）。大画面は `md:` `lg:` で上書き
- **一行あたりの文字数**: 50～80 文字を意識。長文は width を制限

### 具体例

```tsx
// OK - Mobile First
<div className="flex flex-col md:flex-row gap-4 p-4 md:p-6">
  <aside className="w-full md:w-64">Sidebar</aside>
  <main className="flex-1">Content</main>
</div>
```

## ダークモード対応

### ルール

- **ダークモード対応は必須**。`dark:` プレフィックスで暗色版を定義
- **Colors**: shadcn/ui のデフォルトカラー（`bg-background`, `text-foreground` など）を使えば自動対応
- **Contrast チェック**: ダークモード時に WCAG AA 基準（コントラスト比 4.5:1）を満たすこと

### 具体例

```tsx
// OK - 自動ダークモード対応
<div className="bg-background text-foreground border border-input">
  <button className="bg-primary text-primary-foreground hover:bg-primary/90">
    Submit
  </button>
</div>

// 条件付きスタイルが必要な場合
<div className="bg-white dark:bg-slate-950">
  Custom background
</div>
```

## アクセシビリティ（a11y）

### ルール

- **shadcn/ui コンポーネント使用時は自動対応**（Radix UI 準拠）
- **カスタムコンポーネント実装時は以下を必須**:
  - ボタン・リンクに `aria-label` / `title` 属性
  - フォーム要素に `<label>` 紐付け
  - キーボード操作可能（Tab キー、Enter キー）
  - Color only で情報伝達しない（テキスト・アイコン併用）

### 具体例

```tsx
// NG - アイコンのみ、aria-label なし
<button onClick={handleDelete}>🗑️</button>

// OK - テキスト + aria-label
<Button 
  variant="destructive" 
  aria-label="Delete this review comment"
  title="Delete"
>
  <Trash2 className="w-4 h-4" />
</Button>

// OK - フォーム label 紐付け
<label htmlFor="language-select">Language</label>
<select id="language-select">
  <option value="ts">TypeScript</option>
  <option value="py">Python</option>
</select>
```

## Tailwind クラス命名規約

### ルール

- **複合スタイルは抽出してコンポーネント化**（`@apply` よりコンポーネント推奨）
- **Arbitrary values は最小限**。`bg-[#abc123]` より `bg-primary` を優先
- **Responsive classes の順序**: `base` → `sm:` → `md:` → `lg:` → `xl:` → `dark:`

### 具体例

```tsx
// NG - 長い class 属性 + arbitrary values
<div className="flex items-center justify-between p-4 md:p-6 bg-[#f3f4f6] dark:bg-[#1f2937] rounded-lg border border-[#e5e7eb] dark:border-[#374151]">
  ...
</div>

// OK - コンポーネント化
function Card({ children }) {
  return (
    <div className="flex items-center justify-between p-4 md:p-6 bg-gray-100 dark:bg-gray-800 rounded-lg border border-input">
      {children}
    </div>
  )
}

<Card>...</Card>
```

## 動作・アニメーション

### ルール

- **Tailwind の組み込みアニメーション (`animate-spin`, `animate-pulse` など) を活用**
- **複雑なアニメーションは `tailwind.config.ts` で定義**
- **過度なアニメーション：avoid**。ユーザーの `prefers-reduced-motion` を尊重

### 具体例

```tsx
// Loading spinner (Checks API 進行中)
<div className="animate-spin w-4 h-4 rounded-full border-2 border-primary border-t-transparent" />

// Fade-in animation
<div className="animate-in fade-in duration-300">
  Content loaded
</div>

// Disable animation if user prefers
<div className="motion-safe:animate-bounce motion-reduce:opacity-100">
  Nice animation (respects prefers-reduced-motion)
</div>
```
