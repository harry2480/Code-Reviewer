# AI-Review-Agent - サービスドキュメント

## サービス概要

**AI-Review-Agent** は、GitHub Pull Request（PR）において、熟練エンジニアの視点を持つAIが自動レビューを行う GitHub App です。Vercel Hobby環境での運用を前提に、多言語エキスパート・プロンプト、CI同期、自己修正、および AI エージェント連携機能を完備した「究極の個人用開発パートナー」です。

**ターゲットユーザー**: 個人開発者、小規模スタートアップ、学習者

**主な価値**:

- PR の品質を自動で向上させる
- レビュー時間を短縮し、開発効率を高める
- セキュリティ脆弱性・パフォーマンス問題を自動検出
- 複数言語の開発者のコード品質向上を同時にサポート

---

## コンセプト

### 1. 熟練エンジニアの「4つの眼」による自動レビュー

**目的**: 開発者が PR のコード品質をリアルタイムで向上させるための自動フィードバック

**実装内容**:

- **ロジック**: 境界値、例外処理、実行時エラー、破壊的変更の検出
- **セキュリティ**: シークレット露出（自動マスク）、脆弱なパターン（SQL injection、XSS など）の指摘
- **効率性**: 計算量（O(n) 等）、冗長なリソース消費、キャッシュ戦略の改善提案
- **可読性**: 命名規則、SOLID 原則、プロジェクト規約遵守の確認

PR 内の各コード行に対して、4 つの視点でスコアリングし、最優先の改善点を提示。

---

### 2. ポリグロット・エキスパート・モジュール

**目的**: PR 内の複数言語を自動判定し、言語固有のベストプラクティスを動的に注入

**対応言語と特異ルール**:

- **TypeScript**: 型定義の厳密性、非効率な `any` 使用、非 null assertion の禁止
- **Python**: PEP 8 準拠、非効率なリスト内包表記、非同期処理の不備
- **Swift**: 強制アンラップの禁止、メモリ管理（ARC）の考慮
- **PHP**: 型宣言の徹底、PHP 8.x の最新構文活用
- **Go**: エラーハンドリングの徹底、`goroutine` リーク防止
- **Rust**: 所有権と借用の最適化、不要な `.clone()` の指摘

PR ファイルの拡張子から言語を自動判定し、該当する言語エキスパート・プロンプトをシステムプロンプトに注入。異言語混在 PR にも対応。

---

### 3. 自己修正と背景抽出による精密なレビュー

**目的**: ハルシネーション（実在しない API 指摘など）を排除し、より正確で有用なレビューを実現

**二段階検証（Self-Refinement）**:

1. **生成フェーズ**: AI がレビューコメント生成
2. **検証フェーズ**: 別プロンプトで「指摘の正当性」「提案コード の有効性」「根拠の確認」を実施
3. **再生成**: 検証で問題発見時は自動修正または指摘を削除

**背景抽出**:

- 直近のコミットメッセージを参照し、PR の意図を理解
- 呼び出し元の検索を行い、破壊的変更の影響範囲を把握
- 推論に背景情報を反映させ、より精密で実用的なレビューを提供

---

### 4. AI エージェント連携

**目的**: レビューコメントを Cursor や Claude Code に直接貼り付け、自動修正できるワークフロー実現

**連携機能**:

- **Instruction Block**: レビューコメント末尾に「Cursor/Claude Code のチャットに貼り付けるプロンプト」を自動生成
  - 例: `「以下のコードを改善してください（理由：...）。提案されている変更は...」`
- **Suggested Changes**: GitHub 上で即時適用可能なコードスニペット
  - ワンクリックで diff に統合可能
- **Analysis Chain**: 詳細な推論プロセス（Chain of Thought）を `<details>` タグ内に格納
  - PR 画面をスッキリ保ちながら、詳細を必要なときだけ展開可能

---

### 5. CI ステータス同期と予算管理

**目的**: CI の成功時のみ AI レビューを実行し、効率的で確実な品質チェック実現

**CI 同期フロー**:

1. PR に新規コミット → GitHub Actions 自動実行（Lint/Test）
2. CI が **Success** → AI レビュー実行トリガー
3. CI が **Failure** → AI レビュー スキップ（失敗 CI のコードは品質が保証されないため）

**予算管理**:

- 日次のトークン消費を Redis に記録
- 上限（例: 0.5 USD = 約 77 円）に達したら自動停止
- ハードリミット超過時は Checks API で「予算上限超過」と表示

**Checks API による進捗表示**:
```
⏳ AI Review: In Progress (詳細解析中...)
✅ AI Review: Completed (レビューコメント投稿済み)
⏭ AI Review: Skipped (CI Failure のためスキップ)
❌ AI Review: Failed (エラーまたは予算上限超過)
```

---

### 6. 通知集約と開発フロー最適化

**目的**: レビュー通知を最適化し、開発の集中を妨げない

**実装**:

- **バッチ処理**: 1 PR ごとの通知をサマリー 1 通に集約
- **GitHub Checks API**: PR 画面に進捗表示
- **GitHub Comments**: レビューコメントは PR 画面のスレッド形式で投稿

## 期待される効果

1. **開発効率向上** - PR レビュー時間の短縮、自動フィードバックの即座な反映

2. **コード品質向上** - セキュリティ脆弱性・パフォーマンス問題の自動検出、命名規則・設計ルール違反の指摘

3. **学習効果** - 指摘・提案の背景（理由）を学べることで、開発スキル向上を促進

4. **多言語対応** - TypeScript・Python・Go・Rust など複数言語のベストプラクティスを同時サポート

5. **予算効率性** - Vercel Hobby + Upstash 無料枠活用による低コスト運用

## 主要機能

### ユーザー向け

| 機能 | 詳細 |
|---|---|
| **自動PR レビュー** | PR 作成・更新時に自動実行。4つの眼で品質チェック |
| **言語別エキスパート** | TypeScript/Python/Go/Rust など言語固有ルール自動注入 |
| **提案コード** | GitHub の Suggested Changes で即座に適用可能 |
| **Cursor/Claude Code 連携** | レビューコメントを AI エージェントプロンプトに自動変換 |
| **レビュー履歴** | 過去のレビュー指摘を参照・学習 |

### 内部機能

| 機能 | 詳細 |
|---|---|
| **CI 同期** | CI Success 時のみ実行、Failure 時はスキップ |
| **予算管理** | 日次トークン消費監視、ハードリミット自動停止 |
| **自己修正** | 二段階検証でハルシネーション排除 |
| **背景抽出** | コミットメッセージ・呼び出し元検索 |
| **非同期キュー** | Upstash QStash で Webhook 処理を非同期化 |
